ارفع محتويات هذا المجلد مباشرة إلى جذر المستودع، وليس المجلد نفسه.
يجب أن تكون index.html و404.html و.nojekyll ومجلد assets في المستوى نفسه.
بعد الرفع فعّل GitHub Pages من Settings ثم Pages، واختر Deploy from a branch، ثم الفرع main والمجلد /(root).
انتظر اكتمال النشر ثم افتح الرابط الذي يعرضه GitHub.
